============================================
  BOT OFICINA MECÂNICA v3 — OPTIMUS PRIME
  Versão completa com todos os sistemas
============================================

ANTES DE RODAR:
1. Abra o config.json
2. Substitua "SEU_TOKEN_AQUI" pelo token do Discord
   (discord.com/developers/applications → Bot → Reset Token)
3. Configure os IDs dos canais no config.json
4. Configure o cargo "silenciado" para o timeout funcionar

COMO RODAR:
  npm install
  node index.js

============================================
  NOVIDADES DA VERSÃO 3
============================================

AVISOS — FLUXO INTERATIVO COMPLETO:
  /avisar → abre um menu interativo (só você vê):
  1. Botão: escolha o TIPO (Normal / Importante / Reunião)
  2. Seletor: escolha o CANAL onde vai enviar
  3. Pop-up: DIGITA a mensagem
  4. Se Importante/Reunião: Seletor de CARGO para marcar
  → Bot envia no canal escolhido com o cargo marcado

PONTO — REGISTRO DE ENTRADA/SAÍDA:
  /ponto entrada → registra entrada, salva no banco
  /ponto saida   → registra saída + mostra tempo trabalhado
  /pontohistorico @membro → Staff vê o histórico completo

BATE-PAPO SALVO NO BANCO:
  Todas as mensagens do servidor são salvas automaticamente
  /chat @membro       → Staff vê o histórico de mensagens
  /chat @membro 50    → Ver as últimas 50 mensagens
  Últimas 200 mensagens por usuário ficam salvas

SEGURANÇA APRIMORADA:
  Detecta: links, imagens, palavras proibidas, spam
  Punições configuráveis:
    timeout  → silencia por X minutos (padrão)
    ban      → bana permanentemente
    kick     → expulsa do servidor
  Staff não é afetada
  Registra punições no banco de dados

AUTO-LIMPEZA DE CANAIS:
  /limpeza ver                → ver configuração atual
  /limpeza agora #canal       → limpar agora
  /limpeza configurar         → configurar:
    - ativo: sim/não
    - horario: ex "03:00"
    - dias: ex "1,2,3,4,5" (1=seg, 7=dom)
    - canais: IDs separados por vírgula

============================================
  CONFIGURAÇÃO SEGURANÇA (config.json)
============================================

"seguranca": {
  "ativo":            true,
  "banirLinks":       true,    ← bloqueia links externos
  "banirImagens":     true,    ← bloqueia imagens/arquivos
  "maxMensagens":     5,       ← limite anti-spam
  "tempoJanela":      3000,    ← janela do spam em ms
  "punicao":          "timeout", ← "timeout", "ban" ou "kick"
  "timeoutMinutos":   10,      ← minutos se punicao=timeout
  "palavrasProibidas":["palavra1","palavra2"],
  "canaisIgnorados":  [],      ← IDs de canais sem filtro
  "cargosIgnorados":  []       ← IDs de cargos sem filtro
}
